MémoCycle

Supprimer mon compte

La suppression efface tes matières, cours, plannings, historiques et appareils du service MémoCycle. Elle est définitive.

Dans l’application : Profil → Compte et suppression.

Application désinstallée ?

Pour un compte Google, écris SUPPRIMER puis confirme ton identité avec le compte utilisé dans MémoCycle.

Pour un compte Apple, réinstalle MémoCycle, choisis « Continuer avec Apple » puis supprime ton compte depuis le profil. Tu peux aussi contacter l’assistance.
